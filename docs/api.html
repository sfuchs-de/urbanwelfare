API Reference

run_urban_welfare(bilateral_panel, commuting, external_demand, origins = NULL, destinations = NULL, base_time = NULL, estimator = "ols", price_shares = "estimate_by_group", period = NULL, se_method = "delta", ...)

One-call end-to-end pipeline from tidy panel tables. Returns an urban_pipeline list containing $account, $exposures, $fit, $welfare, and $manifest.

urban_from_tables(bilateral_panel, commuting, external_demand, base_time = NULL, origins = NULL, destinations = NULL, ...)

Extracts base-period bilateral spending and external demand from tidy data frames, calibrates omitted budget/sales totals, and returns list(account, shocks, base_time).

urban_account(spending_base, commuting_base, origins, destinations, balance_method = c("reconcile", "ipf", "strict"), commuting_is_share = "auto", tol = 1e-7)

Validates two-sector open-city accounting identities, computes leakage shares, constructs $\Gamma_v$, $\Omega^v$, $M = \Omega^v\Gamma_v$, and $(I - M)^{-1}$, and checks $\rho(M) < 1$.

build_exposures(account, shock_panel, design = c("direct", "shift_share"), center_dest = TRUE, horizons = c(0, 1, 2, Inf))

Computes direct shocks $d_{it}$, infinite-horizon exposures $(\mathbf{F}_t^y, \mathbf{F}_t^v)$, finite-round approximations, and Borusyak–Hull propagated shift-share controls.

estimate_bilateral(panel, exposures, estimator = c("ols", "ppml", "iv"), cluster = c("origin^time", "dest^time"), include_direct = TRUE, use_expected_controls = TRUE, extra_controls = character(0), weights = NULL)

C++ basket-centers destination exposures and estimates Proposition 2.4’s bilateral regression via fixest. Pair with bilateral_from_estimates() for enclave imports, rotemberg_weights() for shift-share diagnostics, and loo_influence() for jackknife checks.

recover_welfare(fit, account, price_shares = "estimate_by_group", level_anchor = c("open_city_factor_balance", "zero"), period = NULL, base_period = NULL, kappa_periods = NULL, kappa_support = NULL, mpc_nonhousing = NULL, psi_O = 0.0, se_method = c("bootstrap", "delta", "none"), n_boot = 300L, seed = 42L)

Recovers relative income and sales responses, estimates sector $\widehat{\kappa}_g^S$, pins down $\widehat{c}_t$ via open-city factor balance (Proposition 2.5), verifies the aggregate terms-of-trade identity, and returns tract and decile welfare incidence.

add_shopping_wedge(welfare, sigma = c(2.0, 3.456, 8.235)) · add_workplace_mobility(welfare, eps = 3.3) · add_finite_bounds(welfare, sigma_ces = 3.456)

Pipe-friendly robustness extensions relaxing fixed shopping amenities, fixed workplaces, and log-linearization.

solve_qsm(account, kappa = NULL, ET_shock = NULL, tau = NULL, sigma_R = 3.456, sigma_T = 7.0, eta_out = 2.5) · optimal_spatial_tax(welfare, account, demand_elasticities = list(sigma_T = 7.0, eta_out = 2.5), sigma_R = 3.456, mode = c("both", "empirical", "nonlinear_qsm"))

C++ damped-Newton nonlinear QSM solver and analytical-adjoint L-BFGS-B optimal uniform and place-specific visitor tax solver with 4-channel Ramsey decomposition.

sim_urban_city(N = 80L, T = 12L, K = 4L, n_visitor_groups = 6L, model = c("ces", "hsa", "iia_het", "kappa_het"), ...)

Generates synthetic multi-sector gravity cities with known nonlinear equilibrium truth. Built-in 160-tract dataset accessible via data(sim_city_160).
