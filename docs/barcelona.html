Barcelona Replication Guide

urbanwelfare applies directly to the empirical setting of Allen, Fuchs, Ganapati, Graziano, Madera, and Montoriol-Garriga (2026, “Urban Welfare: Tourism in Barcelona”), which models 1,053 Barcelona census tracts ($\mathcal{R}$, is_city_resident = TRUE) together with 35 surrounding metropolitan municipalities ($\mathcal{M}$, is_city_resident = FALSE) across 24 months and 5 commercial activity groups.

Workflow on Prepared Barcelona Accounts

library(urbanwelfare)

# 1. Build 1,088-origin (1,053 BCN + 35 Metro) x 1,053-destination open-city account
acct <- urban_account(
  spending_base      = E_R0_all,      # 1088 x 1053 initial resident + metro card spending
  commuting_base     = H_0_all,       # 1088 x 1053 workplace & business-claim shares
  origins            = origins_bcn,   # is_city_resident = TRUE for 1,053 BCN tracts
  destinations       = dests_bcn,     # 5 IO consumer-cut activity groups
  balance_method     = "strict",
  commuting_is_share = TRUE
)
summary(acct)

# 2. Construct network exposures & import enclave Step-1 bilateral estimates (N = 3,260,707)
exps <- build_exposures(acct, shocks_bcn, design = "direct")
fit  <- bilateral_from_estimates(beta_4, exps, vcov = vcov_4x4, n_obs = 3260707L)

# 3. Recover 5-sector price shares on 2018 bank-income support & July vs. January welfare
welf <- recover_welfare(
  fit           = fit,
  account       = acct,
  period        = "201807",
  kappa_support = matching_support_2018,
  se_method     = "bootstrap",
  n_boot        = 1000,
  seed          = 20261004
)
summary(welf)
